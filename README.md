# ☕ Coffee Shop

A modern, responsive coffee shop e-commerce website built with **Next.js, React, TypeScript, and Tailwind CSS**.

This project aims to deliver a smooth and visually engaging online coffee shopping experience through a clean interface, responsive layouts, and carefully crafted animations.

> **Project Status:** Frontend UI completed. E-commerce functionality is currently under development.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/MehtiAbdullahi/Coffee_Shop.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Coffee_Shop
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open your browser and visit:

   ```text
   http://localhost:3000
   ```
